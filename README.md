# Visão Geral do Jogo

**Título Provisório:** Super Retro Drive
**Gênero:** Endless Runner / Corrida Arcade Top-Down
**Plataforma:** Game Boy (Color)

## Breve Descrição:
Um jogo arcade de ritmo acelerado e visão top-down (visto de cima) onde o jogador controla um carro avançando em alta velocidade por uma estrada contínua. O objetivo principal é desviar dos obstáculos (pedras) que surgem no caminho, sobrevivendo o máximo de tempo possível para alcançar a maior pontuação. Conforme o tempo passa, a velocidade do jogo aumenta, testando os reflexos do jogador.

## Core Loop:
1. O jogador acelera pela estrada.
2. Pedras surgem no horizonte (topo da tela).
3. O jogador usa a direção (esquerda/direita) para desviar.
4. O jogador acumula pontos baseados na distância percorrida.
5. Em caso de colisão, o jogo acaba (Game Over) e a pontuação é registrada.
